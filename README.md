## 📌 Sobre o Projeto

O **CartoonCertou** é uma aplicação web interativa de perguntas e respostas (Quiz) com uma interface altamente gamificada e estilizada. O objetivo do projeto foi criar uma experiência de usuário (UX) divertida e engajadora, utilizando um design estilo "cartoon" com cores vibrantes, bordas destacadas e micro-interações dinâmicas.

## ✨ Funcionalidades

* **Setup Dinâmico:** O usuário pode escolher a quantidade de perguntas antes de iniciar a partida.
* **Interface de Jogo (Gameplay):** * Barra de progresso visual.
  * Temporizador (Timer) integrado para cada pergunta.
  * Feedback visual imediato ao selecionar alternativas (animações de acerto ✅ e erro ❌).
* **Tela de Resultados:** Dashboard final exibindo o total de perguntas, contagem de acertos, erros e o cálculo do aproveitamento final (Nota em %).
* **Responsividade:** Design 100% responsivo e fluido, construído pensando na experiência em dispositivos móveis.

## 🛠️ Tecnologias Utilizadas

* **Back-end:** PHP 8+ com framework **Laravel** (Gerenciamento de rotas e processamento das respostas).
* **Front-end:** Motor de templates **Blade** utilizando componentes (`<x-main-layout>`).
* **Estilização:** **Tailwind CSS** avançado (Uso extensivo de pseudo-classes `hover`, animações `animate-bounce`, transformações `transform`, rotações e gradientes complexos).
